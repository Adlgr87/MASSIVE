    CI Python version note

    Environment Python version Notes
    CI (GitHub Actions) 3.11 As specified in pytest.yml
    Local venv 3.14.8 Torch wheels may differ between 3.11 and 3.14

    Risk: torch>=2.2.0 wheels compiled for Python 3.14 may not be available on CI (Python 3.11). Verified: tests pass locally on 3.14, CI runs on 3.11. The torch import guard (tests/test_cfc_lambda_integration.py:14) and skipif markers ensure CI doesn't fail if torch wheels are unavailable.

    CI does NOT install benchmarks package

    Gap found: pytest.yml installs requirements.txt but NOT pip install -e .. The benchmarks module requires editable install to be importable from scripts. This was fixed in the Makefile install target (added pip install -e .). Recommendation: Add pip install -e . to CI workflows if benchmarks are used in CI.
